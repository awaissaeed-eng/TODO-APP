# ✅ TODO-APP

A polished vanilla JavaScript to-do list app built with HTML, CSS, and ES6 JavaScript.
Tasks can be added, edited, deleted, completed, and saved with `localStorage` so they remain after refresh.

---

## 🚀 Features

- ✅ Add new tasks
- ✏️ Edit tasks inline
- 🗑️ Delete tasks
- ✔️ Mark tasks complete / incomplete
- 💾 Persist tasks in `localStorage`
- 🔍 Search tasks by text
- 📌 Filter by all / active / completed
- 🧹 Clear completed tasks
- 🏷️ Categories, priority, and due dates
- 🌗 Dark mode toggle
- 🎯 Drag-and-drop reorder support

---

## 🧩 Project Structure

- `index.html` — app layout and markup
- `style.css` — responsive styling, theme, and layout
- `script.js` — task logic, DOM rendering, event handling, and persistence

---

## 🏁 How to Use

1. Open `index.html` in any modern browser.
2. Type a new task in the field and click **Add**.
3. Toggle the checkbox to mark tasks done.
4. Click the pencil icon to edit a task.
5. Click the trash icon to delete a task.
6. Use the search box to find tasks quickly.
7. Tasks stay saved automatically and remain after page refresh.

---

## 💡 Notes

- Built using plain JavaScript, no external frameworks or libraries.
- Uses modern ES6 features like `const`, `let`, arrow functions, and array methods.
- `localStorage` is used for simple offline persistence.
- Designed for easy customization and extension.

---

## 🛠️ Run Locally

1. Clone or download the repository.
2. Open `index.html` in a browser.
